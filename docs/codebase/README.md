# Codebase onboarding map

This documentation is an evidence-based map of the two independently versioned projects in this workspace: `attendance-backend` and `attendance-frontend`. It was produced from the checked-out source on 2026-08-22. It deliberately separates confirmed facts, strong code inferences, and UNKNOWNs.

Start with [the repository overview](01-repository-overview.md), then [running locally](02-running-locally.md), [architecture](03-architecture.md), and [the newcomer guide](16-newcomer-guide.md).

## Document index

- `01-repository-overview.md` — inventory, technologies, entry points, and scope.
- `02-running-locally.md` — evidence-backed commands and validation results.
- `03-architecture.md` — component and dependency map.
- `04-directory-guide.md` — responsibilities and important files.
- `05-runtime-flows.md` — startup and representative browser/API flows.
- `06-configuration.md` — environment and configuration map.
- `07-data-and-database.md` — MongoDB models and persistence limits.
- `08-testing.md` — tests and quality tooling actually present.
- `09-development-workflow.md` — routine command/reference workflow.
- `10-debugging.md` — observed failures and source-backed diagnostics.
- `11-deployment.md`, `12-observability.md`, `13-external-services.md` — infrastructure evidence and gaps.
- `14-glossary.md` — project terminology.
- `15-unknowns-and-open-questions.md` — items needing maintainer confirmation.
- `16-newcomer-guide.md` — a time-boxed contribution guide.

Do not treat references to a deployed Render/Vercel-looking URL as proof of a currently working production environment; no deployment configuration is checked in.
